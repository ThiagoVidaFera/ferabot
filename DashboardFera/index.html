Como usar

Passo a passo para cada etapa

  1. Abrir o Ferabot Duplo-clique em ABRIR_FERABOT.bat
  2. Copiar o comando da etapa desejada Use o botão "Copiar" ao lado de cada etapa acima
  3. Colar no Claude Code e pressionar Enter Ctrl+V no chat do Claude Code
  4. Responder as perguntas do Claude Ele vai pedir tema, objetivo, tom — responda normalmente
  5. Aprovar a copy antes de gerar as artes Digitar APROVADO quando a copy estiver boa
  6. Pegar os arquivos gerados Ficam em output/ dentro da pasta do Ferabot
