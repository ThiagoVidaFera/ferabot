# eva-hq-ia-noir — skill do Pacote Sistema de Criativos FERA

Skill do Pacote de Skills + Templates do Sistema de Criativos FERA.

## Instalar
1. Tenha o **Claude Code** instalado.
2. Cole esta pasta `eva-hq-ia-noir` dentro de `~/.claude/skills/`
   (Windows: `C:\Users\SEU_USUARIO\.claude\skills\`).
3. Abra o Claude Code e **peça pelo assunto** — ele carrega a skill e executa.

> Caminhos, pixel, e-mail e telefone vêm como **placeholders** (`~`, `SEU_PIXEL_ID`,
> `SEU_NUMERO`, `voce@...`). Troque pelos seus antes de usar.
