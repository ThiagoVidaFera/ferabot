Pré-requisitos

Antes de começar

Você precisa de 2 programas instalados. Clique no link de cada um, faça o download e instale normalmente — como qualquer outro programa. Marque como feito quando terminar.

Claude Code

O aplicativo onde o Ferabot roda. É gratuito e feito pela Anthropic.

Baixar Claude Code

Python 3.10 ou mais recente

A linguagem de programação que roda os scripts do Ferabot. Na instalação, marque obrigatoriamente a opção "Add Python to PATH" antes de clicar em instalar.

Baixar Python

Git (para receber atualizações)

Permite que você receba novas versões do Ferabot com um clique. Instale com todas as opções padrão.

Baixar Git
💡

Reinicie o computador após instalar o Python e o Git. Isso garante que os programas sejam reconhecidos corretamente.

Instalação

Instalando o Ferabot

São 4 passos. Faça um de cada vez, na ordem. Marque cada passo como concluído antes de avançar.

1

Baixar o Ferabot

Abra o terminal do Windows (pressione Windows + R, digite cmd e pressione Enter). Cole o comando abaixo e pressione Enter:

Terminal 
git clone https://github.com/SEU-USUARIO/ferabot.git %USERPROFILE%\Ferabot

Isso cria a pasta Ferabot dentro da sua pasta de usuário (ex: C:\Users\SeuNome\Ferabot).

ℹ️

Não tem terminal? Você também pode baixar o ZIP diretamente do GitHub, extrair e renomear a pasta para "Ferabot".

2

Rodar o instalador

Abra a pasta Ferabot no explorador de arquivos. Localize o arquivo instalar.py e dê duplo-clique nele.

💡

Se aparecer "Com qual programa abrir?", escolha Python ou Python 3.

O instalador vai:

  • Verificar se tudo está instalado corretamente
  • Abrir um formulário no navegador para você preencher seus dados
  • Instalar as 8 skills do Ferabot no Claude Code automaticamente

Siga as instruções que aparecem na tela. Quando terminar, aparece a mensagem FERABOT INSTALADO COM SUCESSO!

3

Preencher o formulário de perfil

Durante a instalação, um formulário vai abrir no seu navegador. Preencha todos os campos com os dados do seu negócio:

  • 🏷️ Seu nome — como você quer ser chamado nos textos
  • 🎯 Seu nicho — quem você atende e qual transformação entrega
  • 📦 Nome do produto — como se chama sua mentoria ou consultoria
  • 💰 Preço — valor do seu produto principal
  • 📸 @ do Instagram — com o @ na frente
  • 🎨 Cores da marca — clique no quadrado colorido para escolher
  • 🔗 Link da landing page — URL da sua página de vendas

As APIs (Gemini, OpenAI) são opcionais agora. Você pode pular e configurar depois.

✅

Após salvar, aparece "Perfil salvo!" no navegador. Pode fechar a aba e voltar pro instalador.

4

Abrir o Ferabot

Volte para a pasta Ferabot no explorador de arquivos. Dê duplo-clique no arquivo:

Arquivo 
ABRIR_FERABOT.bat

O Claude Code vai abrir automaticamente na pasta certa. Se aparecer uma janela de segurança do Windows, clique em "Executar assim mesmo" ou "Sim".

🔥

Instalação concluída! O Ferabot está pronto. Agora você vai criar seu primeiro carrossel.

Primeiro uso

Seu primeiro carrossel

Com o Claude Code aberto na pasta do Ferabot, siga esse passo a passo para criar seu primeiro carrossel de feed.

5

Digitar o comando no Claude Code

Clique na área de chat do Claude Code, copie o comando abaixo e pressione Enter:

Claude Code — chat 
/squad-carrossel-fera
6

Responder o briefing

O Claude vai te fazer algumas perguntas. Responda como se estivesse conversando normalmente:

  • Tema do carrossel — ou diga "pode escolher" e ele sugere
  • Formato — storytelling (história real) ou educativo (dicas)
  • Objetivo — capturar lead, vender produto, ou engajamento
7

Aprovar a copy

O Claude vai gerar o texto dos 10 slides e mostrar para você revisar antes de criar qualquer arte. Leia com calma. Se gostar, escreva:

Claude Code — chat 
APROVADO

Se quiser mudar alguma coisa, basta dizer o que quer ajustar. O Claude corrige e mostra novamente.

💡

Regra de ouro: nunca escreva APROVADO sem ter lido. A copy é o conteúdo que vai sair pro Instagram.

8

Receber os arquivos prontos

Após a aprovação, o Claude vai gerar os 10 slides em PNG. Quando terminar, a pasta de output abre automaticamente no seu computador com os arquivos prontos.

Os arquivos ficam em:

Pasta 
Ferabot\output\carrossel\data-de-hoje\

Copie os PNGs para o celular e publique pelo app do Instagram como um post de carrossel (selecione as imagens na ordem slide-01 → slide-10).

🎉

Parabéns! Você criou seu primeiro carrossel com o Ferabot. Use o mesmo processo para qualquer uma das 8 etapas.

Comandos do Ferabot

Dentro do Claude Code, basta copiar e colar o comando da etapa que você quer usar.

Comando O que cria Formato final

/squad-stories-fera Stories de bastidores com sua foto PNG 1080×1920
/squad-caixinha-fera Stories de caixinha de perguntas PNGs 1080×1920

/squad-isca-fera Isca digital (lead magnet) + página PDF + HTML
/meta-ads-fera Campanhas no Meta Ads Campanha criada no Facebook

/zernio-fera Automação de DMs no Instagram Automação ativa no Zernio
🔄

Para receber atualizações do Ferabot, dê duplo-clique em atualizar.bat na pasta do Ferabot. Tudo é atualizado automaticamente.

Dúvidas frequentes

Perguntas comuns

Isso acontece quando as skills não foram instaladas corretamente. Volte para a pasta Ferabot, dê duplo-clique em instalar.py e aguarde terminar. Depois abra novamente com o ABRIR_FERABOT.bat.

Não se preocupe. Copie toda a mensagem de erro, abra o Claude Code e cole com a pergunta "Encontrei esse erro no Ferabot, o que faço?". O Claude vai diagnosticar e te dar a solução passo a passo.

Abra um terminal na pasta Ferabot (clique com o botão direito dentro da pasta → "Abrir no Terminal") e execute:

Terminal
python SetupFera/setup_form.py

No Claude Code, clique no botão ✏️ Perfil no Dashboard ou abra um terminal na pasta Ferabot e rode:

Terminal
python SetupFera/setup_form.py

O formulário vai abrir com os dados atuais. Edite o que quiser e salve.

Todos os arquivos ficam na pasta output dentro da pasta Ferabot, organizados por etapa e data. Quando a skill termina, a pasta abre automaticamente no explorador de arquivos.

Se precisar encontrar manualmente: Ferabot → output → [etapa] → [data]

O Ferabot em si é gratuito. Você vai precisar de uma assinatura do Claude Code para usar as skills. Algumas etapas avançadas (Meta Ads, Zernio, imagens com IA) usam serviços externos que podem ter custos próprios — mas todos têm planos gratuitos para começar.

🔥
