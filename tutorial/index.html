Passo 1 de 4 — Programa obrigatório

Instalar o Claude Code

Claude Code é o aplicativo onde o Ferabot roda. É como um chat com IA, mas que também consegue criar arquivos no seu computador. Você precisa de uma conta na Anthropic para usar — o cadastro é gratuito.

1

Baixar e instalar o Claude Code

Acesse o site oficial, baixe o instalador para Windows e execute como qualquer outro programa.

  • Acesse claude.ai/download no seu navegador
  • Clique no botão "Download for Windows" — vai baixar um arquivo .exe
  • Quando o download terminar, clique no arquivo baixado para abrir o instalador
  • Se aparecer uma janela de segurança do Windows, clique em "Sim" ou "Executar assim mesmo"
  • O instalador vai rodar e o Claude Code vai aparecer na sua área de trabalho
📺 O que vai aparecer depois de instalar:
Uma janela escura (fundo preto) com um campo de texto na parte de baixo. Parece um terminal, mas funciona como um chat. Essa é a interface do Claude Code — é aqui que você vai digitar os comandos do Ferabot.
💡

Precisa de conta? Sim. Na primeira vez que abrir o Claude Code, vai pedir login. Acesse claude.ai, crie uma conta gratuita com seu email e use as mesmas credenciais no app.

Passo 2 de 4 — Programa obrigatório

Instalar o Python

Python é a "engine" que roda os scripts do Ferabot por baixo dos panos. Tem um detalhe crítico na instalação que a maioria das pessoas esquece — preste atenção no passo 3 abaixo.

2

Baixar e instalar o Python

  • Acesse python.org/downloads
  • Clique no botão amarelo grande "Download Python 3.x.x" — vai baixar um arquivo .exe
  • Abra o arquivo baixado. NÃO clique em "Install Now" ainda. Primeiro, leia o próximo aviso.
⚠️ ATENÇÃO CRÍTICA — faça isso antes de instalar

Na janela do instalador do Python, antes de clicar em qualquer botão, procure e marque a caixa:

Add Python to PATH

Essa caixinha fica na parte de baixo da janela de instalação, antes do botão "Install Now". Se você não marcar essa opção agora, o Ferabot não vai funcionar e você vai precisar reinstalar o Python.

  • Com a caixinha "Add Python to PATH" marcada, clique em "Install Now"
  • Aguarde a barra de progresso completar (leva 1-2 minutos)
  • Quando aparecer "Setup was successful", clique em "Close"
✅ Como verificar se o Python foi instalado corretamente:
Pressione Windows + R no teclado, digite cmd e pressione Enter. Uma janela preta vai abrir. Digite o comando abaixo e pressione Enter:
Terminal (cmd) 
python --version
📺 O que vai aparecer:
Python 3.12.x (ou outra versão 3.x). Se aparecer isso, está perfeito. Se aparecer um erro, o PATH não foi configurado — reinstale o Python e não esqueça de marcar a caixinha.
Passo 3 de 4 — Programa obrigatório

Instalar o Git

Git é o programa que baixa o Ferabot para o seu computador e permite receber atualizações com um clique. A instalação é simples — você só precisa clicar em "Next" em tudo.

3

Baixar e instalar o Git

  • Acesse git-scm.com/download/win
  • Clique em "64-bit Git for Windows Setup" — vai baixar um arquivo .exe
  • Abra o arquivo baixado. Se aparecer aviso de segurança do Windows, clique em "Sim"
  • Vai aparecer uma série de telas com opções. Clique em "Next" em todas elas — as opções padrão são perfeitas
  • Na última tela, clique em "Install" e aguarde
  • Quando terminar, clique em "Finish"
🔄

Reinicie o computador agora. Após instalar o Python e o Git, é necessário reiniciar para que os programas sejam reconhecidos corretamente. Guarde esse tutorial no favorito do navegador antes de reiniciar.

Passo 4 de 4 — Baixar o sistema

Baixar o Ferabot

Agora você vai baixar os arquivos do Ferabot para o seu computador. Tem duas formas de fazer isso — escolha a que você preferir.

4

Baixar via terminal (opção mais rápida)

Esse método baixa e organiza tudo automaticamente em um único comando.

  • Pressione Windows + R no teclado simultaneamente
  • Na janelinha que abriu, digite cmd e pressione Enter
  • Uma janela preta vai abrir — esse é o terminal. Não precisa ter medo, é só um campo de texto
  • Clique no botão "Copiar" abaixo e depois cole no terminal com Ctrl+V (ou clique com o botão direito do mouse e escolha "Colar")
Terminal (cmd) — cole aqui 
git clone https://github.com/ThiagoVidaFera/ferabot.git %USERPROFILE%\Ferabot
  • Pressione Enter e aguarde. Vai aparecer um texto mostrando o progresso do download
  • Quando aparecer "done" ou voltar para a linha de comando, o download terminou
📺 O que vai aparecer durante o download:
Algo como: Cloning into 'C:\Users\SeuNome\Ferabot'... remote: Counting objects... done. — isso é normal e significa que está funcionando.
📁 Onde ficou a pasta:
A pasta Ferabot foi criada em C:\Users\SeuNome\Ferabot (dentro da sua pasta de usuário). Você pode abrir pelo Explorador de Arquivos e navegar até lá.
ou

Baixar via ZIP (alternativa sem terminal)

Se o método acima deu erro ou você prefere não usar o terminal agora, baixe o ZIP diretamente.

  • Acesse github.com/ThiagoVidaFera/ferabot
  • Clique no botão verde "<> Code"
  • Clique em "Download ZIP"
  • Quando o download terminar, clique com o botão direito no arquivo ZIP e escolha "Extrair tudo..."
  • Escolha uma pasta fácil de encontrar, como Documentos ou a Área de Trabalho
  • Vai criar uma pasta chamada ferabot-main — renomeie para Ferabot
⚠️

Atenção: Se você usar o ZIP em vez do terminal, o botão atualizar.bat não vai funcionar para receber atualizações futuras. Para isso funcionar, você precisa ter usado o git clone do passo anterior.

Configuração — Parte 1

Rodar o instalador

O instalador faz tudo automaticamente: verifica se o ambiente está certo, instala o que faltar e prepara o sistema para o próximo passo.

5

Abrir a pasta Ferabot

  • Abra o Explorador de Arquivos (a pastinha na barra de tarefas ou pressione Windows + E)
  • Navegue até C:\Users\SeuNome\Ferabot (troque "SeuNome" pelo seu nome de usuário no Windows)
  • Você vai ver uma série de arquivos e pastas dentro — isso é o Ferabot
📁 Arquivos que você deve ver na pasta Ferabot:
instalar.py  ·  ABRIR_FERABOT.bat  ·  atualizar.bat  ·  pasta SetupFera/  ·  pasta SkillsDoFera/  ·  pasta DashboardFera/
6

Executar o instalador

  • Dentro da pasta Ferabot, localize o arquivo instalar.py
  • Dê duplo-clique nele
  • Se aparecer a janela "Com qual programa deseja abrir este arquivo?", escolha Python ou Python 3 e clique em OK
  • Uma janela preta vai abrir — esse é o instalador rodando. Não feche essa janela
📺 O que vai aparecer na janela preta:
O instalador vai verificar cada componente e mostrar [OK] para os que já estão instalados. Se algum componente estiver faltando (como o Playwright), ele vai perguntar: "Posso instalar X automaticamente agora? (s/n):"
  • Sempre que aparecer "Posso instalar X automaticamente agora? (s/n):", clique na janela preta, digite s e pressione Enter
  • Aguarde cada instalação terminar antes de continuar
💡

O instalador pode demorar alguns minutos se precisar instalar o Playwright (o programa que converte HTML em imagem). Isso é normal — aguarde sem fechar a janela.

📺 O que vai acontecer depois que tudo estiver [OK]:
O instalador vai abrir automaticamente uma aba no seu navegador com um formulário de perfil. Pode parecer que a janela preta "travou" — isso é normal. Ela está aguardando você preencher o formulário.
Configuração — Parte 2

Configurar seu perfil

O perfil é o "coração" do Ferabot. Tudo que você preencher aqui vai ser usado automaticamente em todos os carrosseis, stories, landing pages e anúncios. Preencha com cuidado.

7

Preencher o formulário de perfil

O formulário abriu no seu navegador com fundo escuro. Preencha cada campo:

  • Seu nome completo — como você quer ser chamado nos textos gerados. Ex: "Maria Silva" ou só "Maria"
  • Seu nicho — descreva quem você atende e qual transformação você entrega. Ex: "Ajudo nutricionistas a captar clientes pelo Instagram"
  • Nome do produto principal — como se chama sua mentoria, consultoria ou programa. Ex: "Mentoria Clínica Lucrativa"
  • Preço do produto — valor atual. Ex: "R$ 3.000" ou "R$ 997/mês"
  • @ do Instagram — seu handle com o @ na frente. Ex: "@mariasilva" (sem espaço)
  • Cor primária da marca — clique no quadrado colorido para abrir o seletor de cor. Ou digite o código hex da sua cor (ex: #FF4F00 para laranja)
  • Cor secundária — geralmente branco (#FFFFFF) ou preto (#000000)
  • Link da landing page — URL da sua página de vendas atual. Se não tiver, coloque o link do seu Instagram
  • API Gemini e OpenAI — opcional por agora. Você pode deixar em branco e configurar depois quando for usar as etapas de imagem com IA
✅

Após preencher tudo, clique no botão "Salvar Perfil". A página vai mostrar a mensagem "Perfil salvo com sucesso!". Você pode fechar a aba do navegador.

8

Aguardar a instalação das skills

Depois de salvar o perfil, volte para a janela preta do instalador. Ela vai continuar automaticamente instalando as 8 skills do Ferabot no Claude Code.

📺 O que vai aparecer na janela preta:
Texto rolando com os nomes das skills sendo instaladas. Quando terminar, vai aparecer a mensagem em destaque: FERABOT INSTALADO COM SUCESSO!
🔥

Instalação concluída! O Ferabot está instalado. Você pode fechar a janela preta agora. O próximo passo é abrir o sistema pelo Claude Code.

Configuração — Parte 3

Abrir o Ferabot no Claude Code

Agora você vai abrir o Claude Code dentro da pasta do Ferabot. O Ferabot só funciona quando o Claude Code está aberto nessa pasta específica.

9

Abrir com ABRIR_FERABOT.bat

  • Abra a pasta Ferabot no Explorador de Arquivos (se fechou, vá em C:\Users\SeuNome\Ferabot)
  • Procure o arquivo ABRIR_FERABOT.bat
  • Dê duplo-clique nele
  • Pode aparecer um aviso: "Windows protegeu seu computador" ou "Publisher desconhecido"
  • Clique em "Mais informações" e depois em "Executar assim mesmo" (ou clique em "Sim" se aparecer a janela do Windows Defender)
📺 O que vai acontecer:
Uma janela preta vai aparecer brevemente e depois o Claude Code vai abrir automaticamente, já na pasta do Ferabot. Você vai ver a interface escura do Claude Code com o campo de chat na parte inferior.
💡

O arquivo ABRIR_FERABOT.bat é um atalho que abre o Claude Code já na pasta certa. Você pode arrastar esse arquivo para a sua área de trabalho para facilitar o acesso nas próximas vezes.

10

Entender a interface do Claude Code

Antes de usar, entenda as partes principais da tela:

  • Campo de chat (parte de baixo): onde você digita os comandos e conversa com o Ferabot. Clique nesse campo e comece a digitar
  • Área de resposta (parte do meio): onde o Claude responde, mostra o que foi gerado e faz perguntas
  • Barra lateral (esquerda): mostra os arquivos da pasta Ferabot. Você pode abrir arquivos clicando neles
  • Comandos com /: todo comando do Ferabot começa com /. Digite / no chat e uma lista vai aparecer com os comandos disponíveis
ℹ️

O Claude Code funciona como um chat inteligente. Você pode perguntar qualquer coisa em português, como "O que você pode fazer por mim?" ou "Qual etapa devo usar para criar um carrossel?"

Usando o Ferabot

Criar o seu primeiro carrossel

Com o Claude Code aberto, siga esse passo a passo para criar seu primeiro carrossel de feed do Instagram — do zero até o arquivo PNG pronto para publicar.

11

Chamar a skill de carrossel

Clique no campo de chat na parte de baixo do Claude Code, copie e cole o comando abaixo, e pressione Enter:

Campo de chat do Claude Code 
/squad-carrossel-fera
📺 O que vai acontecer:
O Claude vai ler seu perfil automaticamente e vai começar o processo de criação do carrossel. Ele vai se apresentar e fazer algumas perguntas de briefing para entender o que você quer criar.
12

Responder o briefing

O Claude vai fazer perguntas para entender o que você precisa. Responda em português como se estivesse em uma conversa normal — sem jargão técnico:

  • Tema do carrossel — qual assunto você quer abordar? Ex: "Quero falar sobre como profissionais deixam dinheiro na mesa por não saberem se posicionar". Se não tiver ideia, pode dizer "você escolhe um bom tema para o meu nicho"
  • Formato preferido — quer um carrossel contando uma história real (storytelling) ou com dicas e ensino (educativo)? Se não tiver preferência, pode dizer "qualquer um"
  • Objetivo — o que você quer que o seguidor faça ao terminar de ler? Exemplos: "quero que mande mensagem", "quero que salve para ver depois", "quero capturar o email dele"
💡

Quanto mais detalhes você der, melhor fica o resultado. Mas se não souber responder alguma coisa, pode dizer "você decide" e o Claude vai escolher a melhor opção com base no seu perfil.

13

Ler e aprovar a copy

O Claude vai gerar o texto dos 10 slides e mostrar para você revisar antes de criar qualquer imagem. Leia com atenção:

  • Leia todos os slides apresentados
  • Verifique se o tom está certo, se as informações fazem sentido para o seu nicho
  • Veja se a chamada para ação (último slide) está do jeito que você quer

Se aprovar como está, escreva exatamente isso no chat:

Claude Code — chat 
APROVADO

Se quiser mudar algo, basta descrever o que quer ajustar. Por exemplo:

Exemplos de como pedir ajuste 
// O slide 3 ficou muito técnico, simplifica a linguagem
// Troca o CTA do último slide por "manda 'QUERO' no Direct"
// Reescreve o slide 1, quero começar com uma pergunta
⚠️

Regra de ouro: nunca escreva APROVADO sem ter lido o conteúdo. O texto aprovado vai sair como arte para o Instagram do seu negócio — leia com cuidado.

14

Aguardar os arquivos e publicar

Após o APROVADO, o Ferabot vai renderizar os 10 slides. Esse processo leva de 1 a 3 minutos — aguarde sem fechar o Claude Code.

📺 O que vai acontecer:
O Claude vai mostrar o progresso da renderização. Quando terminar, a pasta de output vai abrir automaticamente no seu Explorador de Arquivos, já com os 10 PNGs prontos.

Os arquivos ficam em:

Localização dos arquivos 
Ferabot\output\carrossel\data-de-hoje\

Para publicar no Instagram a partir do computador, transfira os arquivos para o celular:

  • Via WhatsApp: mande os 10 arquivos para você mesmo em uma conversa pessoal no WhatsApp Web, salve no celular e poste
  • Via Google Drive: arraste os arquivos para uma pasta no Drive, abra no celular e salve na galeria
  • Via cabo USB: conecte o celular ao computador e copie os arquivos para a galeria de fotos

Na hora de postar no Instagram:

  • Crie um novo post e escolha múltiplas fotos (ícone de quadradinhos)
  • Selecione os arquivos na ordem: slide-01, slide-02, slide-03... até o slide-10
  • Adicione sua legenda e publique normalmente
🎉

Parabéns! Seu primeiro carrossel está pronto. O processo para todas as outras 8 etapas é idêntico: chama o comando, responde o briefing, aprova e recebe os arquivos.

Dúvidas frequentes

O que fazer se algo der errado

Isso acontece quando as skills não foram instaladas corretamente. Volte para a pasta Ferabot, dê duplo-clique em instalar.py e aguarde até aparecer "FERABOT INSTALADO COM SUCESSO!". Depois feche o Claude Code e abra de novo com o ABRIR_FERABOT.bat.

Se o problema persistir, abra o Claude Code e diga: "As skills do Ferabot não estão aparecendo, como resolvo?"

Não se preocupe. Faça o seguinte:

1. Selecione toda a mensagem de erro (clique no início do texto vermelho e arraste até o final)
2. Copie com Ctrl+C
3. Abra o Claude Code (com ABRIR_FERABOT.bat)
4. Cole no chat com Ctrl+V e escreva junto: "Encontrei esse erro no Ferabot, o que faço?"
5. O Claude vai diagnosticar e te dar a solução passo a passo

Isso acontece quando o Python foi instalado sem marcar a opção "Add Python to PATH". A solução é reinstalar:

1. Vá em Configurações do Windows → Aplicativos → procure "Python" → clique em Desinstalar
2. Volte ao passo 2 deste guia e reinstale, desta vez marcando a caixinha "Add Python to PATH" antes de clicar em Install
3. Reinicie o computador e tente novamente
