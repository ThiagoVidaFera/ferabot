Passo 1 de 4 — Programas obrigatórios

Instalar o VS Code e a extensão Claude

O VS Code é o editor de código mais popular do mundo — e é gratuito. Dentro dele, você vai instalar a extensão do Claude Code, que é onde o Ferabot roda. Pense no VS Code como a "casa" e no Claude como o "assistente" que mora dentro dela.

1

Baixar e instalar o VS Code

O Visual Studio Code é gratuito e feito pela Microsoft. A instalação é simples — igual a qualquer outro programa.

  • Acesse code.visualstudio.com no seu navegador
  • Clique no botão azul grande "Download for Windows" — vai baixar um arquivo .exe
  • Quando o download terminar, abra o arquivo baixado para iniciar a instalação
  • Clique em "Aceito o acordo" e depois em "Próximo" em todas as telas — as opções padrão são perfeitas
  • Na tela de "Tarefas Adicionais", certifique-se de que a opção "Adicionar ao PATH" está marcada (geralmente já vem marcada)
  • Clique em "Instalar" e aguarde. Ao final, clique em "Concluir"
📺 O que vai aparecer depois de instalar:
O VS Code vai abrir automaticamente. Você verá uma tela de boas-vindas com fundo escuro (ou claro, dependendo do seu sistema). Na lateral esquerda há ícones de navegação — barra lateral de arquivos, pesquisa, extensões, etc.
2

Instalar a extensão Claude Code e fazer login

A extensão do Claude Code transforma o VS Code no ambiente do Ferabot. Você instala direto pelo marketplace de extensões do VS Code.

  • Com o VS Code aberto, pressione Ctrl+Shift+X no teclado — isso abre a aba de Extensões
  • No campo de busca que apareceu, digite Claude Code
  • Vai aparecer a extensão "Claude Code" com o ícone laranja da Anthropic — clique em "Instalar"
  • Aguarde a instalação terminar (leva alguns segundos)
📺 O que vai aparecer depois de instalar a extensão:
Um ícone do Claude (símbolo da Anthropic) vai aparecer na barra de atividades à esquerda do VS Code — é uma coluna estreita com ícones. Pode ser necessário rolar para baixo nessa barra para encontrar o ícone do Claude.
  • Clique no ícone do Claude na barra lateral esquerda
  • Um painel vai abrir pedindo para você fazer login — clique em "Sign in with Claude.ai"
  • Vai abrir uma aba no seu navegador. Se não tiver conta, clique em "Sign up" e crie uma conta gratuita com seu email
  • Após o login no navegador, autorize o VS Code a acessar sua conta — clique em "Allow" ou "Autorizar"
✅ Como saber se o login funcionou:
O painel do Claude no VS Code vai mudar — em vez do botão de login, vai aparecer um campo de chat na parte inferior. É aqui que você vai digitar os comandos do Ferabot.
💡

Plano gratuito é suficiente para começar. O Claude tem um plano gratuito com créditos mensais. Para uso intenso do Ferabot, o plano Pro (US$20/mês) vale muito a pena — mas não é obrigatório para dar os primeiros passos.

Passo 2 de 4 — Programa obrigatório

Instalar o Python

Python é a "engine" que roda os scripts do Ferabot por baixo dos panos. Tem um detalhe crítico na instalação que a maioria das pessoas esquece — preste atenção no passo 3 abaixo.

3

Baixar e instalar o Python

  • Acesse python.org/downloads
  • Clique no botão amarelo grande "Download Python 3.x.x" — vai baixar um arquivo .exe
  • Abra o arquivo baixado. NÃO clique em "Install Now" ainda. Primeiro, leia o próximo aviso.
⚠️ ATENÇÃO CRÍTICA — faça isso antes de instalar

Na janela do instalador do Python, antes de clicar em qualquer botão, procure e marque a caixa:

Add Python to PATH

Essa caixinha fica na parte de baixo da janela de instalação, antes do botão "Install Now". Se você não marcar essa opção agora, o Ferabot não vai funcionar e você vai precisar reinstalar o Python.

  • Com a caixinha "Add Python to PATH" marcada, clique em "Install Now"
  • Aguarde a barra de progresso completar (leva 1-2 minutos)
  • Quando aparecer "Setup was successful", clique em "Close"
✅ Como verificar no terminal do VS Code:
No VS Code, pressione Ctrl+` (acento grave, a tecla que fica abaixo do Esc) para abrir o terminal integrado. Uma janela preta vai aparecer na parte de baixo do VS Code. Digite o comando abaixo e pressione Enter:
Terminal integrado do VS Code 
python --version
📺 O que vai aparecer:
Python 3.12.x (ou outra versão 3.x). Se aparecer isso, está perfeito. Se aparecer um erro, o PATH não foi configurado — reinstale o Python e não esqueça de marcar a caixinha.
Passo 3 de 4 — Programa obrigatório

Instalar o Git

Git é o programa que baixa o Ferabot para o seu computador e permite receber atualizações com um clique. O VS Code integra com o Git automaticamente depois que você instalar.

4

Baixar e instalar o Git

  • Acesse git-scm.com/download/win
  • Clique em "64-bit Git for Windows Setup" — vai baixar um arquivo .exe
  • Abra o arquivo baixado. Se aparecer aviso de segurança do Windows, clique em "Sim"
  • Vai aparecer uma série de telas com opções. Clique em "Next" em todas elas — as opções padrão são perfeitas
  • Na última tela, clique em "Install" e aguarde
  • Quando terminar, clique em "Finish"
🔄

Reinicie o computador agora. Após instalar o Python e o Git, é necessário reiniciar para que os programas sejam reconhecidos corretamente pelo VS Code. Guarde esse tutorial no favorito do navegador antes de reiniciar.

Passo 4 de 4 — Baixar o sistema

Baixar o Ferabot pelo VS Code

Agora você vai baixar os arquivos do Ferabot diretamente pelo VS Code, sem precisar abrir nenhum outro programa. O VS Code tem um recurso nativo chamado "Clone de Repositório" que faz tudo automaticamente.

5

Clonar o repositório pelo VS Code

O VS Code vai baixar todos os arquivos do Ferabot e abrir a pasta automaticamente. Siga cada sub-passo com atenção:

  • Abra o VS Code (se fechou após reiniciar)
  • Pressione Ctrl+Shift+P no teclado — isso abre a Paleta de Comandos, um campo de busca no topo da tela
  • Digite git clone na paleta — vai aparecer a opção "Git: Clone". Clique nela
  • Um campo de texto vai aparecer pedindo a URL do repositório. Clique no botão "Copiar" abaixo e cole a URL com Ctrl+V
URL do repositório — cole na Paleta de Comandos 
https://github.com/ThiagoVidaFera/ferabot.git
  • Pressione Enter após colar a URL
  • Vai aparecer uma janela do Explorador de Arquivos pedindo para você escolher onde salvar a pasta. Escolha um local fácil de encontrar, como Documentos ou a pasta do seu usuário (C:\Users\SeuNome). Clique em "Selecionar como Destino do Repositório"
  • O VS Code vai baixar os arquivos. Você vai ver uma mensagem de progresso no canto inferior direito da tela
  • Quando terminar, vai aparecer uma notificação perguntando "Deseja abrir o repositório clonado?". Clique em "Abrir"
📺 O que vai acontecer depois de clicar em "Abrir":
O VS Code vai carregar a pasta do Ferabot. Na barra lateral esquerda, você vai ver todos os arquivos: instalar.py, SetupFera/, SkillsDoFera/, DashboardFera/ e outros. A pasta está pronta.
💡

Da próxima vez que quiser abrir o Ferabot, basta abrir o VS Code e ir em Arquivo → Abrir Pasta Recente → Ferabot. A pasta vai estar na lista de recentes automaticamente.

Configuração — Parte 1

Rodar o instalador

O instalador faz tudo automaticamente: verifica se o ambiente está certo, instala o que faltar e prepara o sistema para o próximo passo. Você vai rodar ele pelo terminal integrado do VS Code.

6

Abrir o terminal do VS Code e rodar o instalador

O terminal integrado do VS Code já abre direto na pasta correta — sem precisar navegar por nenhuma pasta manualmente.

  • Com a pasta Ferabot aberta no VS Code, pressione Ctrl+` (acento grave, tecla abaixo do Esc) para abrir o terminal. Uma janela preta vai aparecer na parte de baixo do VS Code
  • Confirme que o terminal está na pasta certa — deve aparecer algo como C:\Users\SeuNome\Ferabot> no início da linha. Se estiver, ótimo.
  • Clique no botão "Copiar" abaixo, depois clique no terminal e cole com Ctrl+V
Terminal do VS Code — cole aqui e pressione Enter 
python instalar.py
  • Pressione Enter para executar o instalador
  • O instalador vai verificar cada componente e mostrar [OK] para os que já estão instalados
📺 O que vai aparecer no terminal:
O instalador vai mostrar o status de cada componente. Se algum estiver faltando (como o Playwright), vai aparecer a pergunta: "Posso instalar X automaticamente agora? (s/n):"
  • Sempre que aparecer "Posso instalar X automaticamente agora? (s/n):", clique no terminal, digite s e pressione Enter
  • Aguarde cada instalação terminar antes de continuar
💡

O instalador pode demorar alguns minutos se precisar instalar o Playwright (o programa que converte HTML em imagem). Isso é normal — aguarde sem fechar o terminal.

📺 O que vai acontecer depois que tudo estiver [OK]:
O instalador vai abrir automaticamente uma aba no seu navegador com um formulário de perfil. Pode parecer que o terminal "travou" — isso é normal. Ele está aguardando você preencher o formulário.
Configuração — Parte 2

Configurar seu perfil

O perfil é o "coração" do Ferabot. Tudo que você preencher aqui vai ser usado automaticamente em todos os carrosseis, stories, landing pages e anúncios. Preencha com cuidado.

7

Preencher o formulário de perfil

O formulário abriu no seu navegador com fundo escuro. Preencha cada campo:

  • Seu nome completo — como você quer ser chamado nos textos gerados. Ex: "Maria Silva" ou só "Maria"
  • Seu nicho — descreva quem você atende e qual transformação você entrega. Ex: "Ajudo nutricionistas a captar clientes pelo Instagram"
  • Nome do produto principal — como se chama sua mentoria, consultoria ou programa. Ex: "Mentoria Clínica Lucrativa"
  • Preço do produto — valor atual. Ex: "R$ 3.000" ou "R$ 997/mês"
  • @ do Instagram — seu handle com o @ na frente. Ex: "@mariasilva" (sem espaço)
  • Cor primária da marca — clique no quadrado colorido para abrir o seletor de cor. Ou digite o código hex da sua cor (ex: #FF4F00 para laranja)
  • Cor secundária — geralmente branco (#FFFFFF) ou preto (#000000)
  • Link da landing page — URL da sua página de vendas atual. Se não tiver, coloque o link do seu Instagram
  • API Gemini e OpenAI — opcional por agora. Você pode deixar em branco e configurar depois quando for usar as etapas de imagem com IA
✅

Após preencher tudo, clique no botão "Salvar Perfil". A página vai mostrar a mensagem "Perfil salvo com sucesso!". Você pode fechar a aba do navegador.

8

Aguardar a instalação das skills

Depois de salvar o perfil, volte para o terminal do VS Code. Ele vai continuar automaticamente instalando as 8 skills do Ferabot no Claude Code.

📺 O que vai aparecer no terminal do VS Code:
Texto rolando com os nomes das skills sendo instaladas. Quando terminar, vai aparecer a mensagem em destaque: FERABOT INSTALADO COM SUCESSO!
🔥

Instalação concluída! O Ferabot está pronto. Você pode fechar o terminal (clique no X ao lado de "bash" ou "cmd" na aba do terminal). Agora vamos usar o Claude para criar seu primeiro carrossel.

Usando o Ferabot

Criar o seu primeiro carrossel

Com o Ferabot instalado, você vai usar o painel do Claude dentro do VS Code para criar tudo. O processo é simples: chama a skill, responde o briefing, aprova o texto e recebe os arquivos.

9

Abrir o painel do Claude no VS Code

O painel do Claude é onde acontece tudo. Veja como abrir e entender a interface:

  • Com a pasta Ferabot aberta no VS Code, olhe para a barra lateral esquerda — a coluna estreita com ícones. Procure o ícone do Claude (símbolo da Anthropic, parecido com um diamante ou o logo laranja/cinza da Anthropic)
  • Clique nesse ícone — o painel do Claude vai abrir à direita ou em uma aba separada
  • Você vai ver uma janela de chat com um campo de texto na parte de baixo. É aqui que você digita os comandos
📺 As partes da interface do Claude no VS Code:
Campo de chat (parte de baixo): onde você digita os comandos e conversa com o Ferabot.

Área de resposta (parte do meio): onde o Claude responde, mostra o que foi gerado e faz perguntas.

Comandos com /: todo comando do Ferabot começa com /. Digite / e uma lista vai aparecer com as skills disponíveis.
ℹ️

O Claude entende português normalmente. Você pode perguntar qualquer coisa como "O que você pode fazer por mim?" ou "Qual skill devo usar para criar uma landing page?"

10

Chamar a skill de carrossel

Clique no campo de chat na parte de baixo do painel do Claude, copie e cole o comando abaixo, e pressione Enter:

Campo de chat do Claude — no VS Code 
/squad-carrossel-fera
📺 O que vai acontecer:
O Claude vai ler seu perfil automaticamente e vai começar o processo de criação do carrossel. Ele vai se apresentar e fazer algumas perguntas de briefing para entender o que você quer criar.
11

Responder o briefing

O Claude vai fazer perguntas para entender o que você precisa. Responda em português como se estivesse em uma conversa normal:

  • Tema do carrossel — qual assunto você quer abordar? Ex: "Quero falar sobre como profissionais deixam dinheiro na mesa por não saberem se posicionar". Se não tiver ideia, pode dizer "você escolhe um bom tema para o meu nicho"
  • Formato preferido — quer um carrossel contando uma história real (storytelling) ou com dicas e ensino (educativo)? Se não tiver preferência, pode dizer "qualquer um"
  • Objetivo — o que você quer que o seguidor faça ao terminar de ler? Exemplos: "quero que mande mensagem", "quero que salve para ver depois", "quero capturar o email dele"
💡

Quanto mais detalhes você der, melhor fica o resultado. Mas se não souber responder alguma coisa, pode dizer "você decide" e o Claude vai escolher a melhor opção com base no seu perfil.

12

Ler e aprovar a copy

O Claude vai gerar o texto dos 10 slides e mostrar para você revisar antes de criar qualquer imagem. Leia com atenção:

  • Leia todos os slides apresentados no painel do Claude
  • Verifique se o tom está certo, se as informações fazem sentido para o seu nicho
  • Veja se a chamada para ação (último slide) está do jeito que você quer

Se aprovar como está, escreva exatamente isso no chat:

Claude — campo de chat 
APROVADO

Se quiser mudar algo, basta descrever o que quer ajustar. Por exemplo:

Exemplos de como pedir ajuste 
// O slide 3 ficou muito técnico, simplifica a linguagem
// Troca o CTA do último slide por "manda 'QUERO' no Direct"
// Reescreve o slide 1, quero começar com uma pergunta
⚠️

Regra de ouro: nunca escreva APROVADO sem ter lido o conteúdo. O texto aprovado vai sair como arte para o Instagram do seu negócio — leia com cuidado.

13

Aguardar os arquivos e publicar

Após o APROVADO, o Ferabot vai renderizar os 10 slides. Esse processo leva de 1 a 3 minutos — aguarde sem fechar o VS Code.

📺 O que vai acontecer:
O Claude vai mostrar o progresso da renderização no painel. Quando terminar, a pasta de output vai abrir automaticamente no seu Explorador de Arquivos, já com os 10 PNGs prontos. O VS Code também vai mostrar os arquivos novos na barra lateral de arquivos.

Os arquivos ficam em:

Localização dos arquivos (dentro da pasta Ferabot) 
output/carrossel/data-de-hoje/

Para publicar no Instagram a partir do computador, transfira os arquivos para o celular:

  • Via WhatsApp: mande os 10 arquivos para você mesmo em uma conversa pessoal no WhatsApp Web, salve no celular e poste
  • Via Google Drive: arraste os arquivos para uma pasta no Drive, abra no celular e salve na galeria
  • Via cabo USB: conecte o celular ao computador e copie os arquivos para a galeria de fotos

Na hora de postar no Instagram:

  • Crie um novo post e escolha múltiplas fotos (ícone de quadradinhos)
  • Selecione os arquivos na ordem: slide-01, slide-02, slide-03... até o slide-10
  • Adicione sua legenda e publique normalmente
🎉

Parabéns! Seu primeiro carrossel está pronto. O processo para todas as outras 8 etapas é idêntico: chama o comando no Claude, responde o briefing, aprova e recebe os arquivos na pasta output.

Dúvidas frequentes

O que fazer se algo der errado

Isso acontece quando as skills não foram instaladas corretamente. Abra o terminal no VS Code (Ctrl+`), certifique-se de que está na pasta Ferabot e rode python instalar.py novamente. Aguarde até aparecer "FERABOT INSTALADO COM SUCESSO!". Depois feche o painel do Claude e abra novamente clicando no ícone na barra lateral.

Se o problema persistir, no painel do Claude escreva: "As skills do Ferabot não estão aparecendo, como resolvo?"

Não se preocupe. Faça o seguinte:

1. Clique no início da mensagem de erro e arraste para selecionar tudo
2. Copie com Ctrl+C
3. Clique no painel do Claude na barra lateral
4. Cole no chat com Ctrl+V e escreva junto: "Encontrei esse erro no Ferabot, o que faço?"
5. O Claude vai diagnosticar e te dar a solução passo a passo

Isso acontece quando o Python foi instalado sem marcar a opção "Add Python to PATH". A solução é reinstalar:

1. Vá em Configurações do Windows → Aplicativos → procure "Python" → clique em Desinstalar
2. Volte ao passo 3 deste guia e reinstale, desta vez marcando a caixinha "Add Python to PATH" antes de clicar em Install
3. Reinicie o computador e tente novamente

O formulário abre no endereço http://localhost:8765. Se não abriu automaticamente, abra o navegador e acesse esse endereço manualmente. Certifique-se de que o terminal no VS Code ainda está rodando (não feche a aba do terminal).

Se continuar sem funcionar, abra um novo terminal no VS Code (Ctrl+`) e rode diretamente:

Terminal do VS Code
python SetupFera/setup_form.py

Tente estas opções:

1. Role para baixo na barra lateral — o ícone pode estar mais abaixo dos outros ícones
2. Pressione Ctrl+Shift+P e busque por "Claude" — vai aparecer uma opção "Claude Code: Open" ou similar
3. Se a extensão não foi instalada corretamente, volte ao passo 2 deste guia e reinstale a extensão Claude Code

Existem três formas fáceis:

Opção 1 (mais fácil): Abra o VS Code e vá em Arquivo → Abrir Pasta Recente → Ferabot. A pasta vai estar listada automaticamente.

Opção 2: Navegue até a pasta Ferabot pelo Explorador de Arquivos, clique com o botão direito dentro da pasta e escolha "Abrir com Code" (se essa opção aparecer).

Opção 3: Abra o VS Code, pressione Ctrl+K Ctrl+O (segure Ctrl, pressione K, solte, pressione O) e navegue até a pasta Ferabot.

Depois que a pasta abrir, clique no ícone do Claude na barra lateral para acessar o chat.

A forma mais fácil é pelo WhatsApp Web: abra web.whatsapp.com no computador, crie uma conversa com você mesmo (mande mensagem para o seu próprio número), anexe os arquivos e baixe no celular.

Outras opções: Google Drive (arraste os arquivos para uma pasta no Drive, acesse pelo app do celular), AirDrop se tiver Mac, ou cabo USB conectando o celular ao computador.

Verifique se apareceu alguma pergunta em português no terminal esperando uma resposta (como "Posso instalar X agora? (s/n):"). Se tiver, clique no terminal, digite s e pressione Enter.

Se realmente pareceu travar (mais de 5 minutos sem movimento), feche a aba do terminal, abra um novo terminal com Ctrl+` e rode novamente: python instalar.py. O instalador continua de onde parou.
