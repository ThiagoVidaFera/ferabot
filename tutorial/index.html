O que o Ferabot faz por você

⚡ Como vai ser sua instalação

Passo 1: instala o VS Code e a extensão do Claude (15 minutos, uma vez na vida).

Passo 2: cola um comando no PowerShell que ensina o Claude a baixar projetos automaticamente (10 segundos).

Passo 3: dentro do painel do Claude, escreve "instale https://github.com/ThiagoVidaFera/ferabot". O Claude faz tudo: instala Python, Git, baixa o Ferabot e configura. Você só preenche o seu perfil quando ele pedir.

Passo 1 — Programas obrigatórios

Instalar o VS Code e a extensão Claude

O VS Code é um editor de código gratuito da Microsoft. Dentro dele, você instala a extensão do Claude — é onde o Ferabot vai rodar. Pense no VS Code como a "casa" e no Claude como o "assistente" que mora dentro dela.

1

Baixar e instalar o VS Code

Instalação igual a qualquer outro programa.

  • Acesse code.visualstudio.com
  • Clique no botão azul "Download for Windows" — vai baixar um arquivo .exe
  • Abra o arquivo baixado e clique em "Aceito o acordo" + "Próximo" em todas as telas — as opções padrão são perfeitas
  • Na tela de "Tarefas Adicionais", confira que "Adicionar ao PATH" está marcada
  • Clique em "Instalar" e aguarde. Ao final clique em "Concluir"
📺 O que vai aparecer:
O VS Code abre com uma tela de boas-vindas escura. Na lateral esquerda há ícones de navegação — explorador de arquivos, busca, extensões.
2

Instalar a extensão Claude Code e fazer login

A extensão é o que transforma o VS Code num ambiente onde você conversa com o Claude e roda o Ferabot.

  • Com o VS Code aberto, pressione Ctrl+Shift+X — abre a aba de Extensões
  • No campo de busca digite Claude Code
  • Vai aparecer a extensão "Claude Code" da Anthropic — clique em "Install"
  • Após instalar, um ícone do Claude aparece na barra de atividades à esquerda (a coluna estreita com ícones)
  • Clique no ícone do Claude — um painel abre pedindo login. Clique em "Sign in with Claude.ai"
  • No navegador, faça login (ou crie conta gratuita). Depois autorize o VS Code clicando em "Allow"
✅ Como saber se o login funcionou:
O painel do Claude no VS Code muda — em vez do botão de login, aparece um campo de chat na parte de baixo. É aqui que você vai conversar com o Ferabot.
💡

Plano gratuito é suficiente para começar. Para uso intenso do Ferabot, o Plano Pro (US$20/mês) compensa. Mas não é obrigatório nos primeiros passos.

Passo 2 — A mágica acontece aqui

Instalar o Ferabot em dois comandos

Você vai colar UM comando no PowerShell pra ensinar o Claude a baixar projetos. Depois vai escrever UM comando no painel do Claude pra ele instalar o Ferabot inteiro. O Claude detecta o que falta no seu computador (Python, Git) e instala sozinho.

3

Cole esse comando no PowerShell

Esse comando baixa uma "skill" do Claude — uma instrução que ensina ele a clonar projetos do GitHub e rodar instaladores automaticamente.

  • Aperte a tecla Windows e digite PowerShell
  • Clique em Windows PowerShell nos resultados — uma janela azul vai abrir
  • Clique no botão "Copiar" abaixo, depois clique na janela do PowerShell e cole com botão direito do mouse (no PowerShell, Ctrl+V às vezes não funciona — use o botão direito)
  • Pressione Enter
PowerShell — cole, dê Enter 
New-Item -ItemType Directory -Force -Path "$env:USERPROFILE\.claude\skills\instale" | Out-Null; Invoke-WebRequest -Uri "https://raw.githubusercontent.com/ThiagoVidaFera/ferabot/master/bootstrap/instale/SKILL.md" -OutFile "$env:USERPROFILE\.claude\skills\instale\SKILL.md"; Write-Host "OK — skill /instale instalada" -ForegroundColor Green
📺 O que vai aparecer:
Uma linha verde escrita OK — skill /instale instalada. Pode fechar o PowerShell. Não precisa abrir ele de novo nunca mais.
ℹ️

Esse comando só baixa um arquivo de texto pequenininho (~5KB) com instruções pro Claude. Não instala nada pesado. É um "manual" que ensina o Claude a fazer instalações.

4

No painel do Claude, escreva: instale ferabot

Agora vai a mágica. O Claude vai checar se Python e Git estão instalados, instalar o que faltar, baixar o Ferabot, rodar o instalador e te mostrar o formulário de perfil.

  • Volte pro VS Code (que ficou aberto do passo 2)
  • Clique no ícone do Claude na barra lateral esquerda — o painel abre
  • Clique no campo de chat na parte de baixo
  • Clique no botão "Copiar" abaixo, cole no chat e pressione Enter
Painel do Claude — campo de chat 
instale https://github.com/ThiagoVidaFera/ferabot
📺 O que vai acontecer:
O Claude vai te mostrar tudo que está fazendo, em português. Vai pedir confirmação antes de instalar Python e Git (responda "sim" ou "pode instalar"). Pode demorar de 3 a 8 minutos dependendo da sua internet — sem fechar o VS Code.
🔄

Pode aparecer essa mensagem do Claude: "Acabei de instalar Python/Git, fera. Fecha e abre o VS Code uma vez, aí roda o instale denovo.". Isso é normal — feche o VS Code, abra de novo, clique no ícone do Claude e cole instale https://github.com/ThiagoVidaFera/ferabot mais uma vez. Dessa vez vai direto.

Em algum momento o Claude vai abrir um formulário no seu navegador. Preencha cada campo:

  • Seu nome — como você quer ser chamado nos textos. Ex: "Maria Silva"
  • Seu nicho — quem você atende e qual transformação entrega. Ex: "Ajudo nutricionistas a captar clientes pelo Instagram"
  • Nome do produto — sua mentoria/consultoria/programa. Ex: "Mentoria Clínica Lucrativa"
  • Preço — Ex: "R$ 3.000" ou "R$ 997/mês"
  • @ do Instagram — Ex: "@mariasilva"
  • Cor primária e secundária — clique no quadrado pra abrir o seletor de cor
  • Link da landing page — sua página de vendas atual (ou link do Instagram se não tiver)
  • API Gemini e OpenAI — opcional. Pode deixar em branco e configurar depois

Clique em "Salvar Perfil". Volte pro painel do Claude — ele continua a instalação automaticamente.

🔥

Quando o Claude disser "FERABOT INSTALADO COM SUCESSO!", está pronto. Vamos criar o primeiro carrossel.

Usando o Ferabot

Criar o seu primeiro carrossel

Com o Ferabot instalado, você usa o painel do Claude pra criar tudo. O processo é simples: chama a skill, responde o briefing, aprova o texto e recebe os arquivos.

5

Chamar a skill de carrossel

No painel do Claude, copie e cole o comando abaixo no chat e pressione Enter:

Painel do Claude 
/squad-carrossel-fera
📺 O que vai acontecer:
O Claude lê seu perfil automaticamente, se apresenta e faz algumas perguntas de briefing pra entender o que você quer criar.
6

Responder o briefing

Responda em português como uma conversa normal:

  • Tema do carrossel — qual assunto? Ex: "Como profissionais deixam dinheiro na mesa por não saberem se posicionar". Sem ideia? Diga "você escolhe um bom tema pro meu nicho"
  • Formato preferido — quer storytelling (história real) ou educativo (dicas)? Sem preferência? Diga "qualquer um"
  • Objetivo — o que o seguidor deve fazer ao final? Ex: "mandar mensagem", "salvar pra ver depois", "deixar email"
💡

Quanto mais detalhes, melhor o resultado. Mas se não souber, diga "você decide" e o Claude escolhe com base no seu perfil.

7

Ler e aprovar a copy

O Claude vai gerar o texto dos 10 slides e mostrar pra você revisar antes de criar qualquer imagem.

  • Leia todos os slides apresentados
  • Verifique se o tom está certo pro seu nicho
  • Confira o CTA (último slide)

Se aprovar, escreva exatamente isso no chat:

Claude — chat 
APROVADO

Se quiser mudar algo, descreva o ajuste:

Exemplos de ajuste 
// O slide 3 ficou muito técnico, simplifica a linguagem
// Troca o CTA do último slide por "manda 'QUERO' no Direct"
// Reescreve o slide 1, quero começar com uma pergunta
⚠️

Regra de ouro: nunca escreva APROVADO sem ter lido. Texto aprovado vira arte pro Instagram do seu negócio.

8

Aguardar os arquivos

Após o APROVADO, o Ferabot renderiza os 10 slides. Leva 1-3 minutos — sem fechar o VS Code.

📺 O que vai acontecer:
O Claude mostra o progresso. Ao terminar, a pasta de output abre automaticamente com os 10 PNGs prontos.

Os arquivos ficam em:

Pasta dos PNGs (dentro de Ferabot/) 
output/carrossel/data-de-hoje/
9

Publicar no Instagram

Pra postar no Instagram, transfira os arquivos pro celular:

  • WhatsApp Web: mande os 10 arquivos pra você mesmo numa conversa pessoal, salve no celular e poste
  • Google Drive: arraste os arquivos pra uma pasta no Drive, abra no celular e salve na galeria
  • Cabo USB: conecte o celular ao computador e copie os arquivos pra galeria

Na hora de postar:

  • Crie um post escolhendo múltiplas fotos (ícone de quadradinhos)
  • Selecione na ordem: slide-01, slide-02, slide-03... até slide-10
  • Adicione legenda e publique
🎉

Parabéns! Primeiro carrossel publicado. O processo das outras 8 etapas é idêntico: chama o comando no Claude, responde briefing, aprova, recebe arquivos.

Dúvidas frequentes

O que fazer se algo der errado

Isso é normal — o PATH do Windows só atualiza em janelas novas. Feche completamente o VS Code, abra de novo, clique no ícone do Claude e cole instale https://github.com/ThiagoVidaFera/ferabot mais uma vez. Dessa vez ele vai encontrar Python/Git e continuar.

Possíveis causas:

1. Você usou Ctrl+V no PowerShell antigo — ele às vezes não cola assim. Tente colar com botão direito do mouse em vez de Ctrl+V.

2. Política de execução bloqueada — abra o PowerShell como Administrador (botão direito → "Executar como administrador") e cole o comando de novo.

3. Sem internet ou GitHub fora do ar — confira sua conexão e tente daqui a alguns minutos.

Significa que a skill do passo 3 não foi instalada. Confira:

1. Abra o Explorador de Arquivos do Windows e vá em C:\Users\SeuNome\.claude\skills\instale\

2. Deve existir um arquivo SKILL.md nessa pasta

3. Se não existir, volte ao passo 3 e cole o comando do PowerShell de novo

4. Após confirmar que o arquivo existe, feche e reabra o VS Code, clique no Claude e tente instale ferabot novamente

1. Role pra baixo na barra lateral — o ícone pode estar abaixo dos outros

2. Pressione Ctrl+Shift+P e busque "Claude" — vai aparecer "Claude Code: Open"

3. Se nada disso funcionar, a extensão não foi instalada. Volte ao passo 2.

O formulário abre em http://localhost:8765. Se não abriu sozinho, copie esse endereço e cole no seu navegador. O Claude continua aguardando você preencher.

Se mesmo assim não funcionar, escreva no painel do Claude: "o formulário do perfil não abriu, e agora?"

Sem stress. Volte pro chat e responda sim ou pode instalar. O Claude continua de onde parou.

Vai com o Claude:

1. Selecione e copie a mensagem de erro

2. Cole no painel do Claude

3. Escreva junto: "Encontrei esse erro instalando o Ferabot, o que faço?"

4. O Claude vai diagnosticar e te dar a solução
